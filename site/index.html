A multilingual CMS for Laravel

Add a page tree, runtime fields and a translated admin to the Laravel app you already know. People and AI agents edit through the same safe actions.

Read the docs GitHub
composer require lynxcms/core lynxcms/admin

Open source under the MIT license. Lynx is in pre-release, so its APIs may change before 1.0.

Two sites built with Lynx

Both are open source starter apps. Install one, change it, and read how it works.

Arcturus Systems

A corporate website in English and Portuguese. Editors arrange the home page section by section and pick the pages each section shows.

  • Demo admin

Castor & Otters

A wildlife law firm in Vancouver and Montreal, in English and French. Its website and its meeting rooms app are one Laravel app. Staff book rooms on the site, in the admin or through an AI assistant, and a TV in each lobby and a tablet at each door show what is free.
