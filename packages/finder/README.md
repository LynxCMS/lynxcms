# lynxcms/finder

> [!NOTE]
> This is a read-only split of [`packages/finder`](https://github.com/LynxCMS/lynxcms/tree/main/packages/finder) in the [Lynx CMS monorepo](https://github.com/LynxCMS/lynxcms). Open issues and pull requests there. Lynx is not ready for production yet: see its README.

Page Finder for the Lynx CMS admin: search every page by its fields, template, status and dates, with conditions grouped by all and any.

## Installing

```bash
composer require lynxcms/finder
```

See the [installation guide](https://github.com/LynxCMS/lynxcms/blob/main/docs/getting-started/installation.md) and [Page Finder](https://github.com/LynxCMS/lynxcms/blob/main/docs/modules/finder.md).
