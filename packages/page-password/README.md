# lynxcms/page-password

> [!NOTE]
> This is a read-only split of [`packages/page-password`](https://github.com/LynxCMS/lynxcms/tree/main/packages/page-password) in the [Lynx CMS monorepo](https://github.com/LynxCMS/lynxcms). Open issues and pull requests there. Lynx is not ready for production yet: see its README.

Password-protected pages for Lynx CMS (pagePassword): a password set on a page locks it and the pages below it for visitors.

## Installing

```bash
composer require lynxcms/page-password
```

See the [installation guide](https://github.com/LynxCMS/lynxcms/blob/main/docs/getting-started/installation.md).
