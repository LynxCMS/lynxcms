# lynxcms/seo

> [!NOTE]
> This is a read-only split of [`packages/seo`](https://github.com/LynxCMS/lynxcms/tree/main/packages/seo) in the [Lynx CMS monorepo](https://github.com/LynxCMS/lynxcms). Open issues and pull requests there. Lynx is not ready for production yet: see its README.

SEO for Lynx CMS: meta and social tags, canonical links, robots rules and robots.txt, per template SEO fields.

## Installing

```bash
composer require lynxcms/seo
php artisan lynx:migrate   # asks whether the database is backed up
```

See the [installation guide](https://github.com/LynxCMS/lynxcms/blob/main/docs/getting-started/installation.md).
