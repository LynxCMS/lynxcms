# lynxcms/page-references

> [!NOTE]
> This is a read-only split of [`packages/page-references`](https://github.com/LynxCMS/lynxcms/tree/main/packages/page-references) in the [Lynx CMS monorepo](https://github.com/LynxCMS/lynxcms). Open issues and pull requests there. Lynx is not ready for production yet: see its README.

Reports on the links between Lynx CMS pages: broken links, pages nothing links to, and the most linked pages, with the health of the page references index.

## Installing

```bash
composer require lynxcms/page-references
```

See the [installation guide](https://github.com/LynxCMS/lynxcms/blob/main/docs/getting-started/installation.md) and [Page References](https://github.com/LynxCMS/lynxcms/blob/main/docs/modules/page-references.md).
