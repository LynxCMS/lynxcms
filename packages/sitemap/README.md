# lynxcms/sitemap

> [!NOTE]
> This is a read-only split of [`packages/sitemap`](https://github.com/LynxCMS/lynxcms/tree/main/packages/sitemap) in the [Lynx CMS monorepo](https://github.com/LynxCMS/lynxcms). Open issues and pull requests there. Lynx is not ready for production yet: see its README.

XML sitemaps for Lynx CMS: every published page in every language, split into parts past a limit set in config or the admin.

## Installing

Lynx is not on Packagist yet: see [Trying it](https://github.com/LynxCMS/lynxcms#trying-it) in the monorepo's README.
