      What changed from today's field screens

      • Kinds in plain words. The type is a choice of what the field holds, grouped and described for people ("Paragraphs", "Blocks"), instead of a select of type names with descriptions written for agents.
      • Label first. The name templates use is made from the label, shown as $page->name, and locks once the field exists.
      • Settings with real controls. Each kind's settings get labels and inputs of their own: the add button's text in every language, "At least / at most" for limits, a choice of how blocks start, instead of a form built from the agent schema.
      • Formatters as switches. Smart quotes, new-tab links and heading anchors are things to turn on, not a wall of "Add smartypants" buttons.
      • Blocks without nested cards. Block types sit in a list on the left; the chosen one's fields in the middle; the page editor's view of it on the right, updating as widths change. Limits and display move to their own tab, so the page no longer runs 2,000 pixels.
      • Repeaters use the same builder, with one item instead of a list of block types.
      • Save at the top, as in the page editor, and "Used by" under the title, where it warns before an edit instead of after.
