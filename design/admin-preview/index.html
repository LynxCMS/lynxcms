What changed from today's admin

  • Plain type. Geist for headings, labels and text, instead of Inter and monospace headings; monospace stays for addresses only. Screen titles are larger, and each screen has one primary action.
  • The mark's facet carries language state. Solid: its own text. Light: shows English. Outline: not in that language yet. The same shape in the tree, the language switch and every field.
  • Two views of the tree. Simple, the default, keeps today's minimal rows. Details adds each page's address, languages, status and last change, with filters for drafts, scheduled and untranslated pages.
  • An editor that reads top to bottom. Labels above fields, grouped sections, language tabs on each translatable field, and a side panel for publishing, translation and history.
  • Translation hints are optional. The sentences explaining which fields show English stay hidden unless the editor turns them on, next to the theme in their account menu.
  • Still white label. Every tone comes from the accent. Choose Client branding: the accent changes and the Lynx mark gives way to the client's name.
  • Illustrative content. Pages, people and dates are invented for the preview.
